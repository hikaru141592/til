## 学習内容1  
- **タグ**: 乱数, 議事乱数
- **タイトル**: ランダム生成された数式をビュー上に表示させる
- **内容**:  
  1. ある程度複雑な処理になるので、コントローラのprivateメソッドではなくサービスオブジェクトapp/services/arithmetic_quiz.rb等を作る。
  2. クラスの中で定義するメソッドにはメソッド名に`self.`がつくものとつかないものがあり前者はクラスメソッド、後者はインスタンスメソッドとなる。
  3. シード(seed)の概念
    - 擬似乱数: 真の乱数ではなく、決定的に計算された数列を乱数っぽく扱ったもの。
    - シード(seed): 乱数列の「初期値」。同じシードを使うと同じ乱数列が再現できる。テストやデバッグ時に毎回同じ結果を得たいときに重要。
    ```
    rng1 = Random.new(42) # ジェネレータを作成
    rng2 = Random.new(42)

    puts rng1.rand(1..10)   # => 7  (例: 1回目の呼び出しは数列1つ目の値になる。)
    puts rng1.rand(1..10)   # => 3  (例: 2回目の呼び出しは数列2つ目の値になる。)

    puts rng2.rand(1..10)   # => 7  (別のジェネレーターでもseedが同じなので上の例と同じ結果)
    puts rng2.rand(1..10)   # => 3

    # シードなし: 毎回異なる乱数列
    rng3 = Random.new
    rng4 = Random.new

    puts rng3.rand(1..10)   # => 5  (例)
    puts rng4.rand(1..10)   # => 7  (例)
    ```
    - seedをplay_stateの更新時刻値等から参照すればページリロードをしても生成内容は変わらない（ページリロードした場合は再度ジェネレータが作成され数列1つ目の値になる）。
    - result = x.public_send(:+, y)について、public_sendは第一引数を:メソッドを表すシンボル（つまり`:`が頭に必要）と評価し呼び出し（publicメソッドに限られる）、第二引数を呼び出しメソッドの引数とする。
    - 生成された複数の不正解値の配列は.shuffle(random: rng)で順を入れ替える。
      - RubyのArray#shuffle（あるいは Enumerable#shuffle）メソッドは、配列内の要素をランダムに並び替え（シャッフル）して新しい配列を返す。
      - shuffleにはキーワード引数`random:`を渡せるようになっていて、そこにRandomオブジェクトを指定すると、その乱数発生器を使ってシャッフルを行う。

## 学習内容2  
- **タグ**: Ruby
- **タイトル**: ある配列を使って「〈A〉を配列の1つ目の要素に、〈B〉を配列の2つ目の要素に・・・置換する」
- **内容**: 
@options.each_with_index do |opt, idx|
                      placeholder = "〈#{('A'.ord + idx).chr}〉"
                      orig.gsub!(placeholder, opt.to_s)
                    end
配列をarrayとし、置換させたい文言を含むテキストをtextとする。
```
array.each_with_index do |st, idx| # 配列から一つ目の要素から順にその要素とインデックスを取り出す。
  placeholder = "〈#{('A'.ord + idx).chr}〉" # `.ord`でAを文字コードに変換しインデックスの数値を加え文字に戻す。
  text.gsub!(placeholder, st)
end
```
