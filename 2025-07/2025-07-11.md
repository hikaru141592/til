## 学習内容1  
- **タグ**: Github
- **タイトル**: GitHubにプッシュしたブランチ名に見えないUnicode “‐”(U+2010) が混入
- **内容**: 
通常のASCIIハイフン`-`と異なるもので、Git操作が失敗。以下のような対応をとった。
```
# 誤ってpushしたリモートブランチ削除
git push origin --delete 'feature/37-add-fortune‐telling-event'

# ローカルブランチをリネーム（ASCII版）
git branch -m feature/37-add-fortune-telling-event

# その後再プッシュ
```

## 学習内容2  
- **タグ**: Rails
- **タイトル**: Railsでの曜日取得
1. Date.current と Date.today の違い
  - `Date.today`はサーバーのタイムゾーンに依存  
  - `Date.current`はRailsの`config.time_zone`を考慮した現在日付を返す  
  ```
  # config.time_zone = 'Tokyo'
  Date.today       # => 2025-07-11 (サーバーUTCで計算された日付)
  Date.current     # => 2025-07-11 (Tokyoタイムゾーンでの今日)
  ```
2. wdayメソッド
  - Date#wdayは曜日を整数（0:日曜日〜6:土曜日）で返すメソッド
3. 文字列として曜日を取得する
  - strftimeを使う
  ```
  today = Date.current
  today.strftime("%w")   # => "5"
  today.strftime("%A")   # => "Friday"
  today.strftime("%a")   # => "Fri"
  ```
4. 日本語の曜日名を得る
  - I18n を使う（config/locales/ja.yml に以下を追加）
  ```
  ja:
    date:
      day_names: ["日曜日", "月曜日", "火曜日", "水曜日", "木曜日", "金曜日", "土曜日"]
      abbr_day_names: ["日", "月", "火", "水", "木", "金", "土"]
  # ビューやコードで以下のように利用
  # I18n.l(Date.current, format: '%A')  # => "金曜日"
  # I18n.l(Date.current, format: '%a')  # => "金"
  ```
