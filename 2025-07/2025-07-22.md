# til/2025-07-22.md

## 学習内容1  
- **タグ**: ビュー, ブラウザ
- **タイトル**: html.erbファイルを修正した後、コンテナ再起動しないとブラウザに反映されない事象への対応
- **内容**: 
  1. ブラウザ側のキャッシュ確認
    - ハードリロード（Ctrl + Shift + RやDevTools で Disable cache）を試す
    - 別ブラウザ・プライベートモードでも変化なし、ブラウザキャッシュではないと確定
  2. Turbo (Hotwire) キャッシュ疑い
    - レイアウト全体に <meta name="turbo-cache-control" content="no-cache"> を追加
    - 反映されない
  3. テンプレートがそもそも反映されていない疑い
    - `docker compose exec web nl -ba /app/app/views/.../show.html.erb`でコンテナ内の中身を確認したが最新
    - コントローラ・ビューが毎リクエストで再レンダリングされているログを確認したところ「Rendered …show.html.erb」と正常に毎回出る
    - Rails側は確実に最新テンプレを返している
  4. ブラウザ開発者ツールでNetworkのResponseで最新HTMLが届いていない
    - DevToolsのNetworkのResponseを確認したが反映されていない
    - どこかで完成したHTMLがさらにキャッシュされている状態
  5. 開発モードのキャッシュ機能確認
    - docker compose exec web rails dev:cache を実行し、“Action Controller caching enabled for development mode.”と“Action Controller caching desabled for development mode.”の切り替えを複数回行った
    - どちらに切り替えてもビューが反映されたが、いずれにおいても切替後ファイル更新すると反映されない
    - 開発環境でビュー／コントローラキャッシュが有効化されている様子
  6. file_watcherの切り替えを試す
    - `config.file_watcher = ActiveSupport::FileUpdateChecker`をdevelopment.rbに追加
    - 効果なし
  7. config/environments/development.rbの`config.cache_classes = true`と`config.eager_load = true`
    - いずれもfalseにしたところ解決
    - これによりクラス再ロードもテンプレート再読み込みも完全に無効化されていた
    - rails dev:cache は「キャッシュ ON/OFF トグル」の副作用でプロセスを揺り動かすため一瞬だけ反映
