## 学習内容1  
- **タグ**: ruby
- **タイトル**: 数値の範囲判定
- **内容**: 
```
# 1. Range オブジェクトの生成
r1 = 2..6    # 2,3,4,5,6の範囲
r2 = 2...6   # 2,3,4,5の範囲

# 2. 範囲内か判定するメソッド
# 2.1 between?(min, max): レシーバーの数値が min ≤ n ≤ max のとき true を返す
n = 4
n.between?(2, 6)    # true
n.between?(2, 4)    # true（端点も含む）

# 2.2 Range#cover?: 範囲オブジェクトがobjを含むかを判定
# 数値の比較だけなので高速
(2..6).cover?(4)    # => true
(2..6).cover?(6)    # => true（端点含む））

# 2.3 Range#include?: cover? と似ているが、要素を列挙して含有をチェックすることも可能（数値Rangeではcover?と動作同等）
(2..6).include?(4)  # => true
[ 1, 3, 4 ] .include?(4)  # => true

```
使い分けのポイントは、
  - 可読性重視: between?
  - パフォーマンス重視: cover?, include?
  - 配列チェックしたい: include?
