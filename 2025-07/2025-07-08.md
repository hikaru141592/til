## 学習内容1  
- **タグ**: git
- **タイトル**: pushを中断してしまい再度pushしようとしたら「Everything up-to-date」
- **内容**: 
コミット自体はすでにリモートのGitリポジトリに受け付けられているがビルド（slug作成）とリリースは完了していない。  
空コミットを作って再プッシュするなど何かコミットを追加する必要がある。
```
git commit --allow-empty -m "Trigger Heroku rebuild"
git push heroku main
```
これで「diffがある」と認識され、ビルドとリリースが再度走る。
