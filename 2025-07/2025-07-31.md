## 学習内容1  
- **タグ**: モーダル
- **タイトル**: モーダルが勝手にもう一度開くバグを直すまでに学んだこと
- **内容**: 
  1. モーダルとイベントの基本
    - BootstrapのモーダルはJSインスタンスで操作する  
      ```
      const modal = bootstrap.Modal.getOrCreateInstance(element)
      modal.show()  // 開く
      modal.hide()  // 閉じる
      ```
    - 完全に閉じた瞬間にhidden.bs.modalというカスタムイベントが発火する

  2. 勝手に再表示が起きるよくあるパターン
    - ボタン → fetchなど非同期処理開始、ユーザーがすぐ閉じる
      - 少し遅れてfetch完了 → modal.show() がもう一度実行、レースコンディションで二重表示
  3. レースを止めるコード
    ```
    // フラグ変数を導入
    this.isClosed = false           // 開く前はfalse
    this.modalTarget.addEventListener(
      "hidden.bs.modal", () => { this.isClosed = true } // 閉じたらtrue
    )

    // fetch完了時にガード
    fetch("/status")
      .then(r => r.text())
      .then(html => {
        if (this.isClosed) return   // 閉じていれば何もしない
        this.frameTarget.innerHTML = html
        this.modal.show()           // ← 1 回だけ
      })
      ```
  4. DevToolsでのデバッグ
    - console.log() + performance.now() で呼び出し順を見る
    - console.trace() でどこから呼ばれたか（スタック）を見る
