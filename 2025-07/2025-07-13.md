## 学習内容1  
- **タグ**: Github, git
- **タイトル**: 作業ツリーやステージの変更はそのままでmainブランチの状態までコミット履歴を戻す
- **内容**: 
`git reset --soft main`とすることでmainブランチから作業ブランチを切ったときまでコミット履歴を戻せる。`--soft`オプションにより作業ツリーとステージの変更は一切そのまま維持。  
なお`--mixed`オプションを使うとコミット履歴とステージの変更は戻し作業ツリーはそのままにできる（`--mixed`はデフォルトのオプションなので省略も可）。

## 学習内容2  
- **タグ**: Github, git
- **タイトル**: 画像を３層で重ねる
- **内容**:
  1. CSSのpositionとレイアウトフロー
  - position: static（デフォルト）
    - ドキュメントフローに乗る。親要素の高さを担保する。
    - z-indexは無効（効かない）。
  - position: absolute/relative等
    - フローから外れて自由に配置できる。
    - z-indexの階層ルールに乗る。
  2. static要素を残す
  全部を非static（例えばposition-absolute等）にすると、親の高さが0になりcollapseしてしまう。どれか１つはstatic（背景画像など）に残しておくとフロー要素が高さを確保してくれる。
  3. スタッキングコンテキストとz-indexの振る舞い
    - z-indexが負の値の要素
    - static（非配置）要素
    - z-indexが0の配置要素
    - z-indexが正の配置要素
