- 特異クラスの継承
  - クラスCはクラスDの子（c < d）の場合
    - クラスC自身の特異クラスの親は、元のクラスの親Dの特異クラス。
  - クラス（モジュール）CがモジュールDをMixinしている場合（include、extend）
    - Cの親はDだが、クラスC自身の特異クラスの親はDとならない
  - 上記どちらの場合であっても（Cはクラス）
  - クラスCのインスタンスの特異クラスの親は、元のクラスC
- メソッド内でのブロック呼び出し
  - block.yield、yield、block.callが可能
  - yield.callは不可なので注意
- クラス変数の探索
  - メソッド定義の中
    - ネストは見に行かず自分のクラスとその継承関係だけを探す。
  - クラス/モジュール定義（直下）
    - レキシカルスコープ（ネスト）から優先して探す。
- 定数
  - const_getの定数探索
    - selfを見に行き、なければそこから継承を辿る
  - メソッド内で定数直接代入 (CONST = 1)はSyntaxError
    - const_setを使えばメソッド内でも可
- メソッドの大文字定義
  - エラーではない（非推奨）
  - メソッド名指定だけでは呼ぶことができず、selfか()をつける必要がある
  - 定数と競合する場合、上記の通りselfか()をつけた場合のみメソッドが呼ばれる
- スコープ内とスコープ外に同じ名前のクラスがあり継承する場合
  - クラス名は定数なので暦sカルスコープから優先的に探索
  - ただしスコープ内であっても親とするクラスが下に記述がある場合は無視される。
- proc,lambda
  - 定義の仕方
   - proc
    - Proc.new { |a, b| [a, b] }
    - proc { |a, b| [a, b] }
  - lambda
    - lambda { |a, b| [a, b] }
    - ->(a, b) { [a, b] }
  - 呼び出し方(共通)
    - .call
    - .yield
    - []
    - .()
    - ===
  - returnした時
    - proc: メソッドごと処理を終了する
    - lambda: そのブロックだけを終了しメソッドの処理を続ける
- 正規表現を使った真偽値等の判定
  - `=~`: マッチした位置を返す
    - 左辺右辺を問わない
  - `match?`: 真偽値を返す
  - `match`: マッチオブジェクトかnilを返す
  - `str.include?`: 引数に正規表現を引数に取ることはできない
- returnとbreak
  - returnはメソッドそのものを抜けるがbreakは一つのループ（ブロック）しか抜けない
- private
  - 子クラスから丸見え
    - superで呼べる
    - メソッド名指定で呼べる
- protected
  - 同じクラス（または継承関係）の「他のインスタンス」からでも呼べる。
    - otherを引数で受け取り`other.protected_method`のように使える
- rubyコマンドのオプション
  - I(include):
    - 指定されたディレクトリを&LOAD_PATHに追加
    - requireやloadメソッド使用時に検索される
    - 環境変数RUBYLIBに追加することはない
  - w(warning):
    - 冗長モード実行、普段出力しないワーニングも出力
    - 似たオプションとして、W0,W1,W2,W(warning)
      - 出力範囲を指定したワーニング実行
      - WとW2では全出力
  - e(execute):
    - ファイル実行ではなく直接与えたコードを実行
  - n(next):
    - 実行ファイルと別でテキストファイルを用意し、その各行に対しループ処理をし実行ファイルを実行
    - neの組み合わせにするとテキストファイルの各行に対しループ処理をし、直接書いたコードを実行
    - 各行は$_に格納される
    - p(print):nと同等の処理をしその結果を自動でprint
    - a(Autosplit):nやpとセットで使い、各行を自動的に分割し$Fという配列に格納
      - デフォルトでは空白で分割されます。
    - F(Field separator):分割するときの区切り文字を直後に指定（fはない）
  - 他
    - h(Help):ヘルプ表示
    - v(version):バージョン表示（Vはない）
    - c(compile):指定ファイルの文法チェック（実行はしない
    - r():スクリプト実行前に指定されたファイルを実行？？？ライブラリををrequire???
    - d(debug):デバッグモード
    - l():chompのように改行文字を取り除き、さらにprint時出力元に改行がなくてもそれぞれ改行する
    - -s(script): スクリプト引数をグローバル変数として扱う。???
  - 備考
    - Fは直後に区切り文字指定、eは実行コード指定する都合上、後ろに他のオプションを続けてはいけない
    - tやfはない。
- case whenとcase in
  - 「AまたはBまたはCに該当」
    - when: `,`で区切る
    - in: `|`で区切る
  - 一致するwhenやinがないとき
    - when: nilが返る
    - in: 例外
  - ハッシュ同士を比較
    - whenもinも内容が完全に一致するかを判定する
  - case when限定
    - `===`で比較している
    - `case A; when B`だったら`B === A`で判定

- Time.iso8601
  - `time_object.iso8601 => "2024-03-23T15:30:45+09:00"`のような形式で文字列出力
    - 年月日は`-`で繋ぐ
    - 時間は`:`で繋ぐ
    - 時間の手前に`T`
    - タイムゾーンは`+09:00"`のような形式、もしくは`Z`
  - `Time.iso8601("2024-03-23T15:30:45+09:00")`のようにするとTimeオブジェクトを生成する。
  - `require 'time'`がないとNoMethodError
- Time.strftime
  - `日時データ.strftime(書式の文字列)`で文字列出力する
  - 記号の意味
    - %F	日付 (ISO 8601形式)	Full date	2024-03-23
    - %D	米国式日付 (月/日/年)	Date (US)	03/23/24
    - %T	時刻 (24時間)	Time	15:30:45
    - %R	時刻 (時:分)	Relax (秒なし)	15:30
    - %u: 曜日 (月曜=1, 日曜=7) ※数字で出るのがポイント。
    - %z: タイムゾーン (+0900)。
    - %Z: タイムゾーン名。
  - 紛らわしいやつ
    - `time_object.strftime("%F %T") => "2024-03-23 15:30:45"`
    - (間にスペースがあり、タイムゾーンがない)
  - strftimeはTimeクラスの標準メソッドなので、`require 'time'`が不要
- Time.parse
  - `require 'time'`がないとNoMethodError
- Time.strptime
  - 時間を表す文字列とフォーマットの文字列を引数で与えTimeオブジェクトを生成
  - ブロックを渡すとブロック引数で年数を返す（`%Y`は4桁、`%y`は2桁）、値を編集できる
    - `Time.strptime('91/5/18 4:13:00', '%Y/%m/%d %T')`は0091年になる
    - 1900を足したり2000を足したりする処理をブロックで書く
  - `require 'time'`がないとNoMethodError

- Regepex
  - 特殊変数(`"Ruby31" =~ /([a-z]+)(\d+)/i`を例にする)
  - $~ : #<MatchData "Ruby31" 1:"Ruby" 2:"31">（マッチデータ全体）
  - $& : "Ruby31"（最後にマッチした文字列）
  - $1 : "Ruby"（1番目のカッコ）
  - $2 : "31"（2番目のカッコ）
  - $+ : "31"（最後のカッコ）
  - $` : ""（最後にマッチした文字列、今回でいう"Ruby31"の手前の文字列）
  - $' : ""（最後にマッチした文字列、今回でいう"Ruby31"の後ろの文字列）
