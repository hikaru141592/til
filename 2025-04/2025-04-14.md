## 学習内容1
- **タグ**: ruby,ラップ
- **タイトル**: enumでラップする
- **内容**:
coin.rbを
```
class Coin
  ONE_HUNDRED = 100
  FIVE_HUNDRED = 500
end
```
とし、
drink_type.rbを、
```
class DrinkType
  COKE = 1
  DIET_COKE = 2
  TEA = 3
end
```
とする、
test.rbについて、
def test_500円でコーラを購入
-   drink = @vm.buy(500, Drink::COKE)
+   drink = @vm.buy(Coin::FIVE_HUNDRED, DrinkType::COKE)
    change = @vm.refund

-   assert_equal(Drink::COKE, drink.kind)
-   assert_equal(400, change)
+   assert_equal(DrinkType::COKE, drink.kind)
+   assert_equal([Coin::ONE_HUNDRED] * 4, change)
end
このように変更する。
①投入金額と購入ドリンク種類をenumとしてラップした。
②assert_equalはテストコードで使われるアサーション（=「○○であるべき！」という主張）、assert_equal(期待する値, 実際の値)と使う。

## 学習内容2
- **タグ**: ruby
- **タイトル**: dupについて
- **内容**:
```
  def refund
    result = @change.dup
    @change = []
    result
  end
```
のdupがない場合、@change = []をした際にresultも空になってしまう。
dupは配列やハッシュなどのオブジェクトをコピーしたいときに使う。
