## 学習内容2
- **タグ**: アセット
- **タイトル**: アプリに使用する画像の配置場所について
- **内容**:
(1)アセットパイプライン（app/assets/images/）
○：デプロイ時にも削除されない（git で管理できる）
×：public/ に比べて手軽にアクセスできない（適切なヘルパーを使う必要がある）
(2)public/ フォルダ（public/images/ など）
○：Railsを介さずに直接参照できる（CDNで配信したい画像には適している）
×：アセットパイプラインの恩恵を受けられない（圧縮・最適化なし）
×：本番環境のデプロイ時に削除される可能性がある（管理方法に注意が必要）
(3)storage/（Active Storage を使用）
○：ユーザーがアップロードした画像を管理するのに適している
×：設定が必要（特に本番環境ではストレージの設定が必須）

## 学習内容6
- **タグ**: numericality,バリデーション
- **タイトル**: numericalityについて
- **内容**:
numericalityとは数値であることを保証するためのバリデーションのオプション。
以下が例。
```
validates :eyecatch_width, numericality: { 
    only_integer: true, 
    greater_than_or_equal_to: 100, 
    less_than_or_equal_to: 700 
  }
```
また以下のようにすると任意の数値を許す。
```
validates :eyecatch_width, numericality: true
```

## 学習内容8
- **タグ**: 403,render
- **タイトル**: render file: Rails.root.join('public', '403.html')について
- **内容**:
```
render file: Rails.root.join('public', '403.html'), status: :forbidden, layout: false
```
について
ルートディレクトリを取得するために、Rails では Rails.rootを使う
```
render file: Rails.root.join('public', '403.html')のRails.root.join('public', '403.html')
```
はRailsのルートディレクトリに配置されたpublic/403.htmlである
status: :forbidden は、HTTPステータスコードを 403 に設定することを意味する（「このリソースへのアクセス権限がない」ことを示す）
railsでは、通常のビューをレンダリングするときに app/views/layouts/application.html.erb のレイアウト を適用するが、
layout: false を指定すると、レイアウトなしで純粋なHTMLのみを表示できる

## 学習内容10
- **タグ**: Pundit,権限,Policy
- **タイトル**: Punditとは
- **内容**:
Pundit は、Rails アプリケーションで権限管理を行うための軽量なライブラリ。
主に Policy（ポリシー） というクラスを使って、各リソース（例: 記事、ユーザー、コメントなど）に対するアクセス制御を実装。
gemの追加、bundle install後、アプリ全体で Pundit を使用できるように、ApplicationController に include Pundit を追加。
Pundit では、各モデルごとに Policy クラス を作成し、ユーザーの権限を定義します。
例えば、Articleのアクセス権を管理する ArticlePolicy を作成する場合、以下のようにする
```
rails g pundit:policy article
```
app/policies/article_policy.rbが作成される
作成された ArticlePolicy に、各アクションごとのアクセス制御を定義する。

## 学習内容11
- **タグ**: Pundit,ハンドリング
- **タイトル**: PunditのNotAuthorizedErrorのハンドリング
- **内容**:
app/controllers/application_controller.rbでの
```
rescue_from Pundit::NotAuthorizedError, with: :user_not_authorized(※privateメソッド)
```
は
```
rescue_from エラーの種類, with: :メソッド
```
としたもので、Punditによる権限がなかった場合にどのメソッドを実行するかを定義している。
※config/application.rbまたはconfig/environments/production.rbで
```
config.action_dispatch.rescue_responses["Pundit::NotAuthorizedError"] = :forbidden
```
を記述しても同様。

## 学習内容14
- **タグ**: joins
- **タイトル**: scopeによる関連テーブルの検索
- **内容**:
Articleモデルにおける
```
scope :body_contain, ->(word) { joins(:sentences).where('sentences.body LIKE ?', "%#{word}%") }
```
について、Article モデルに
```
has_many :sentences, through: :article_blocks
```
という関連がありjoins(:sentences) を使うことで、articles テーブルと sentences テーブルを結びつける
(sentences.bodyはArticle モデルに関連のあるsentencesのbodyカラム)
