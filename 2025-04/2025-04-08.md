## 学習内容1
- **タグ**: ActiveStorage
- **タイトル**: has_one_attachedとhas_many_attached
- **内容**:
Siteモデルにおいて、
has_one_attached :og_image
has_many_attached :main_images
とするとSiteモデルの各レコードは一つのog_imageと複数のmain_imageを持つことができるようになる。
これらはActive Storageの機能でActiveStorageが裏で画像ファイルを専用のテーブルに保存して、
どのSiteにどの画像が紐づくかを管理してくれる。

- **タグ**: バリデーション
- **タイトル**: バリデーションのオプション
- **内容**:
validates :main_images, attachment: { purge: true, content_type: %r{\Aimage/(png|jpeg)\Z}, maximum: 524_288_000 }
について、

content_type: %r{\Aimage/(png|jpeg)\Z}は正規表現を使ってpngかjpegファイルに限定している。
maximum:はファイル上限の設定。

## 学習内容4
- **タグ**: SimpleForm,フォーム
- **タイトル**: SimpleFormとは
- **内容**:
SimpleFormは、form_forやform_withをもっとシンプルで見やすく書けるようにするためのライブラリ。
※form_forはform_withの古い書き方。
-通常のRailsフォーム-
```
<%= form_for @post do |f| %>
  <%= f.label :title %>
  <%= f.text_field :title %>
<% end %>
```
-SimpleForm-
```
= simple_form_for @post do |f|
  = f.input :title
```
labelやinputフィールド、バリデーションメッセージなんかを自動で出力してくれる。

## 学習内容8
- **タグ**: アセット,JavaScript,CSS
- **タイトル**: アセット、アセット管理ツールとは
- **内容**:
RailsではJavaScriptやCSSなどのファイル（＝アセット）をまとめて管理・読み込みたい。
しかしファイルが増えると管理が面倒になる上読み込む順番を間違えると動かない。
そこでRailsではアセット管理ツールを使い効率的に扱えるようにしている。
アセット管理ツール①
(1)Sprockets（スプロケッツ）
Railsに昔からある管理ツール。
JavaScriptやCSSを読み込むときに //= require などの「ディレクティブ」で順番を指定する
※ディレクティブは、Sprocketsでファイルの読み込み順などを指定する特別なコメントのこと
主にRails6以前で標準だった
-例-
```
//= require swiper
//= require my_custom_script
```
これはswiper.jsを読み込んでからmy_custom_script.jsを読み込むという指示。
(2)Webpacker（ウェブパッカー）
Rails 6から登場した新しい管理ツール。
JavaScriptのモジュールバンドラー「Webpack」を使う。
npmパッケージで管理、ES6のimportが使える。
-例-
```
import Swiper from 'swiper';
```
Node.jsやnpmを使って、モダンなJavaScript開発ができる

## 学習内容10
- **タグ**: アセットパイプライン,node_modules
- **タイトル**: node_modulesのライブラリをRailsで使えるようにする
- **内容**:
Railsでは、JavaScriptやCSSなどのファイル（アセット）を管理して、ページに読み込めるようにする仕組みがある。
その仕組みのひとつがアセットパイプライン（Sprockets）である。
一方で、最近のJavaScriptライブラリ（たとえばSwiperやBootstrap）は、npm や Yarn というツールでインストールするのが一般的である。
インストールされたライブラリは、Railsプロジェクトの中のnode_modulesフォルダに入る。
しかしRailsのアセットパイプラインは最初の状態ではこのnode_modulesを見てくれないので、
```
# config/initializers/assets.rb
Rails.application.config.assets.paths << Rails.root.join('node_modules')
```
を追加する必要がある。
※Rails.application.config.assets.pathsはどこのフォルダを見ればアセットがあるのかRailsに教えてあげるためのリスト。

## 学習内容11
- **タグ**: JavaScript,package.json
- **タイトル**: package.jsonとは
- **内容**:
JavaScriptのライブラリ（パッケージ）を管理するファイル。
package.jsonは、JavaScriptプロジェクトの「設定ファイル」のようなもので、
どのライブラリを使っているか、どういう設定か が全部書かれてる。
Railsでwebpackerやimportmap-railsを使ってたりするならプロジェクトのルートにpackage.jsonがある。
-例-
```
{
  "name": "my-rails-app",
  "private": true,
  "dependencies": {
    "swiper": "^10.0.4",
    "bootstrap": "^5.3.0"
  },
  "scripts": {
    "build": "webpack --mode production"
  }
}
```
dependencies：使ってるライブラリ（パッケージ）の一覧。ここに書かれると、npm installなどで自動的にインストールされる。
※package.jsonにパッケージを追加した後はnpm installやyarn installを実行すること。
scripts：よく使うコマンドを登録できる。たとえば npm run build等。
name, version, description：プロジェクトの情報。

## 学習内容12
- **タグ**: CDN
- **タイトル**: CDN
- **内容**:
インターネット上にある「ファイル配信サービス」のこと。
-例-
```
<script src="https://unpkg.com/swiper/swiper-bundle.min.js"></script>
```
このようにすると(Swiperの)JavaScriptファイルを外部のサーバーから読み込むという意味になる
npmやyarnで自分のPCにダウンロードしなくても、またnode_modulesもなくてもとりあえず動く。
ただし通信速度が遅くなったり安定性に欠けたり(CDNが落ちたらJavaScriptが動かなくなる)セキュリティの懸念から本番環境では次の理由で推奨されないことが多い。
