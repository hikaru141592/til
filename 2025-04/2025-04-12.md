## 学習内容1
- **タグ**: メール
- **タイトル**: app/mailers/application_mailer.rbについて
- **内容**:
ApplicationMailerクラスは、全てのメール送信者（Mailer）が継承する基本のMailerクラスで、このクラスには共通の設定を定義する。
```
class ApplicationMailer < ActionMailer::Base
  default from: 'from@example.com'  # メールの送信元を設定
  layout 'mailer'  # メールのレイアウトを指定
end
```
例えばこのように設定できるが、このときlayout 'mailer'はメールのHTMLレイアウトをapp/views/layouts/mailer.html.slimに定義することを意味する。

## 学習内容3
- **タグ**: Github
- **タイトル**: app/views/layouts/について
- **内容**: 
リモートの設定を削除・差し替えして自分のGitHubに作ったリポジトリに紐づけ直す
課題等のリポジトリをクローンして作業してた場合、そのリポジトリは他人（学校や講座の運営など）のGitHubリポジトリに紐づいてる可能性がある。
そのままpushしても「自分のGitHubアカウントの草（＝コミット履歴）」には反映されないことが多いので以下のような操作をする。

①今のリモートリポジトリを確認する
```
git remote -v
```
これを打つと今のリモートリポジトリのURLが出てくる。
②リモートの設定を削除する
```
git remote remove origin
```
今のリモートとの関連が解除される。
③削除後自分のGitHubで新しくリポジトリを作りそのURLで紐づけ直す。
git remote add origin https://github.com/自分のユーザー名/自分のリポジトリ名.git
その後pushする。
```
git push -u origin main(or master) 
```

## 学習内容5
- **タグ**: Ruby
- **タイトル**: word.chars.each_with_indexについて
- **内容**: 
①
word.charsは文字列が格納された変数wordを文字の配列に変換
(例：word = "あらるん"の場合、word.charsは["あ", "ら", "る", "ん"])
②
each_with_index
each_with_indexは、配列（または文字列）を順番に走査し、各要素とそのインデックス（位置）をブロックに渡すイテレータ。
例えば、["あ", "ら", "る", "ん"]という配列に対して以下のようにeach_with_indexを使うと、
```
["あ", "ら", "る", "ん"].each_with_index do |char, index|
  puts "#{index}: #{char}"
end
```
出力は、
```
0: あ
1: ら
2: る
3: ん
```
となる。

## 学習内容6
- **タグ**: Ruby,正規表現
- **タイトル**: Rubyにおける正規表現について
- **内容**: 
正規表現 /[\s,\.]+/
/.../は「正規表現リテラル」を示します。/で囲まれた部分が「正規表現」として解釈される。
[\s,\.]+ の意味
\s: 空白文字を表す（スペース、タブ、改行など）。
,: コンマを意味する。
\.: ピリオドを意味する。ピリオド自体は正規表現で特殊な意味を持つため、エスケープ処理している。
[...]: 中括弧内のいずれかの文字に一致する。ここでは空白文字、コンマ、ピリオドのいずれかに一致する。
+: 直前の要素（ここでは[\s,\.]）が1回以上繰り返されることを意味する。
