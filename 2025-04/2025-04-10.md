## 学習内容1
- **タグ**: letter_opener,メール
- **タイトル**: letter_openerとletter_opener_web
- **内容**:
letter_opener ：メール送信するとすぐにブラウザが自動で開いて、メール内容を表示してくれる
letter_opener_web　：letter_openerにアクセスして過去の送信メール一覧をブラウザで見られる

## 学習内容2
- **タグ**: letter_opener,メール
- **タイトル**: letter_opener_web使うときの追加ステップ
- **内容**:
①
Gemfileに追加（開発環境のみ）
```
group :development do
  gem 'letter_opener_web'
end
```
②
ルーティングを追加（routes.rb）
if Rails.env.development?
  mount LetterOpenerWeb::Engine, at: "/letter_opener"
end
メールを送ったあと http://localhost:3000/letter_opener にアクセスすればOK

## 学習内容3
- **タグ**: letter_opener,メール
- **タイトル**: letter_opener_web使うときのホスト名やポート番号の設定
- **内容**:
config/environments/development.rbに、
```
  config.action_mailer.delivery_method = :letter_opener_web
```
だけでなく
```
  config.action_mailer.default_url_options = { host: 'localhost:3000' }
```
も含まれる場合、これはメール本文にリンクを含めるとき（例えばパスワードリセットURL、アカウント確認URLなど）ホスト名やポート番号が必要になるため追加されたものである。

## 学習内容5
- **タグ**: whenever
- **タイトル**: wheneverコマンドのエラー
- **内容**:
wheneverコマンドで以下が表示される場合、
## [message] Above is your schedule file converted to cron syntax; your crontab file was not updated.
## [message] Run `whenever --help' for more options.
これはwheneverコマンドがcronスケジュールを表示したことを示しているが、実際にcronの設定ファイルが更新されていないことを伝えている。
これは通常、wheneverがcrontabに設定を追加するために、実際のシステムでの権限が不足している場合に起こる。
docker compose exec web bundle exec whenever --update-crontabで解決。
