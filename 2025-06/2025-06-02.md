## 学習内容1  
- **タグ**: Sorcery, reset_password, submodules  
- **タイトル**: Sorceryの`:reset_password`サブモジュールを有効化する  
- **内容**:  
  1. サブモジュールとは  
     - Sorceryは認証機能をモジュール単位で拡張できる。`submodules = [:activity_logging]` のように配列で指定する。  
     - `:activity_logging` → 最終ログイン日時などを自動で記録する機能。  
     - `:reset_password` → パスワードリセット用のトークン生成・メール送信・パスワード変更のメソッドを提供する機能。  
  2. 設定手順  
     1. `config/initializers/sorcery.rb` に `:reset_password` を追加する：  
        ```
        Rails.application.config.sorcery.submodules = [:activity_logging, :reset_password]
        ```  
     2. マイグレーションで `users` テーブルに必要なカラムを追加し、モデル側でバリデーションを追加
  3. Sorceryの提供メソッド  
     - `user.deliver_reset_password_instructions!(url)`  
       トークンを生成・保存し、指定したURLを本文に含めたメールを送信する。  
     - `User.load_from_reset_password_token(token)`  
       トークンをもとにユーザーを検索し、かつ有効期限内ならユーザーを返す。  
     - `user.change_password(new_password, password_confirmation)`  
       トークンの有効性チェック、パスワードバリデーション、暗号化保存、トークンカラムのクリアを実行する。  

## 学習内容2  
- **タグ**: ActionMailer, SMTP, letter_opener_web, 環境設定  
- **タイトル**: ActionMailerと外部SMTP サービスの関係・letter_opener_webの使い方  
- **内容**:  
  1. ActionMailer だけではメールを外に送れない理由  
     - RailsにはActionMailerという「メールを組み立てて送信指示を出す仕組み」がある。しかし実際に外部にメールを届けるにはSMTPサーバーの設定が必要。  
     - SMTPサーバーはGmail、SendGrid、Mailgun、Amazon SESなどの外部サービスを指し、本番環境ではこれが必要。  
  2. letter_opener_web の役割  
     - 開発環境では外部SMTPに投げず、送信されたメールをブラウザ上でプレビューできるgem。  
     - `Gemfile`の`group :development do gem 'letter_opener_web' end` を追加し、`development.rb` に次を追記する。  
       ```
       config.action_mailer.delivery_method = :letter_opener_web
       config.action_mailer.perform_deliveries = true
       config.action_mailer.default_url_options = { host: 'localhost', port: 3000 }
       ```  
     - 送信すると `/letter_opener`エンドポイントにメール一覧が表示され、クリックすると中身を確認できる。  
  3. 本番環境での SMTP 設定  
     1. 例として以下のように書く。  
        ```
        config.action_mailer.delivery_method = :smtp
        config.action_mailer.default_url_options = { host: ENV['HOST_NAME'] }
        config.action_mailer.smtp_settings = {
          address:              ENV['SMTP_ADDRESS'],
          port:                 ENV['SMTP_PORT'] || 587,
          domain:               ENV['SMTP_DOMAIN'],
          user_name:            ENV['SMTP_USERNAME'],
          password:             ENV['SMTP_PASSWORD'],
          authentication:       'plain',
          enable_starttls_auto: true
        }
        ```
     2. `ENV[...]`の環境変数はHerokuのConfig Varsやローカルの`.env`で設定する。
