## 学習内容1  
- **タグ**: ngrok
- **タイトル**: ngrok（エングロック）とは
- **内容**:  
ローカルで立ち上げたウェブアプリケーションを外部に簡単に公開できるサービス。  
http://localhost:3000 と併せてngrokを立ち上げると他の人もこのアプリケーションにアクセス可能に。　　
つまり外部に（世界に）公開される。
例えばLINEログインはHTTPSのコールバックを必須とするためngrokを使わないと開発環境で動作させることができない。  
インストールしサインアップし、ダッシュボードで確認できる認証トークン登録コマンドを行うことで、以降`ngrok http 3000`コマンドで起動できる。

## 学習内容3  
- **タグ**: ngrok
- **タイトル**: 開発環境でngrok経由のホストを許可する
- **内容**: 
RailsはデフォルトでHostヘッダーをチェックし、許可リストにないドメインからのアクセスを遮断する。  
config.hostsは許可するホスト名のリストであり、開発環境であればconfig/environments/development.rbを編集する。  
なおngrokのFreeプランではセッションごとにサブドメインが変わるので、ワイルドカードでまとめて許可する方法がいい。
```
Rails.application.configure do
  # ngrok-free.app ドメインのサブドメインをまとめて許可（正規表現）
  config.hosts << /[a-z0-9\-]+\.ngrok-free\.app\z/
end
```
※[a-z0-9\-]+ ：小文字アルファベット、数字、ハイフンの並びを１文字以上

## 学習内容6  
- **タグ**: LINE認証, Rspec
- **タイトル**: LINE認証エラー
- **内容**:
「This channel is now developing status. User need to have developer role.」というメッセージは、このLINEチャネルはまだ開発中モードのためチャネルの開発者として登録されたLINEアカウントでしかログインできないというメッセージ。  
故にテスト用LINEアカウントを開発者に追加するかチャネルを公開に切り替える必要がある。
