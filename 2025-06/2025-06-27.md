## 学習内容2  
- **タグ**: Ruby, nil
- **タイトル**: blank?メソッド
- **内容**:
blank?はRails（ActiveSupport）が標準のRubyクラスに追加しているメソッドで、単にnilかどうかだけでなく値が空かどうかを広く判定する。
```
nil.blank? #=> true
"".blank? #=> true
" ".blank? #=> true
[].blank? #=> true
{}.blank? #=> true
false.blank? #=> true
```
なお、
  - nil?を使うとnilだけを判定する。
  - empty?は""nil.empty?でtrueを返すがnil.empty?はエラー。
  - present?は!blank?（blank?の否定）と同じ。
