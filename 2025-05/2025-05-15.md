## 学習内容1  
- **タグ**: Importmap, ESモジュール  
- **タイトル**: ImportmapとESモジュールの基本  
- **内容**:  
  - ESモジュールはブラウザ上で`import/export`構文を使ってJSを分割読み込みする仕組み  
  - importmapはESモジュールの読み込み先をRails側で設定する仕組み  
  - `preload: true`を指定すると`<link rel="modulepreload">`が自動生成される  
  - `preload: true`を指定しないとmodulepreloadタグが出ない  

## 学習内容2  
- **タグ**: ディレクトリ構造, フィンガープリント  
- **タイトル**: fingerprint付きファイルとディレクトリの使い分け  
- **内容**:  
  - フィンガープリント付きファイルは`application-30f68313.js`のようにハッシュを付けてキャッシュ管理する仕組み  
  - `vendor/javascript`はpin時の元ファイルを保存する場所  
  - `public/assets`はプリコンパイル後のfingerprint付きファイルを配置する配信用フォルダ  
  - 本番環境ではpublic/assetsのファイルをそのままブラウザが読み込む  

## 学習内容3  
- **タグ**: ファイル確認, HTTPステータス  
- **タイトル**: curl -IとContent-Typeの見方  
- **内容**:  
  - `curl -I URL`で返ってくる最初の行にステータスコード（200,404など）が出る  
  - `Content-Type`ヘッダーは返されたデータ形式（`text/javascript`や`text/html`）を示す  
  - ステータスが200でContent-Typeが`text/javascript`ならJSファイルが正しく返っている  
  - ステータスが404やContent-Typeが`text/html`ならファイルが見つからずHTMLが返っている

## 学習内容4  
- **タグ**: ダウンロード, CDN  
- **タイトル**: 正しいCDN URLからのファイル取得  
- **内容**:  
  - URLを間違えるとHTMLや“Not Found”が混入したファイルになる  
  - Turbo用CDN例: `https://ga.jspm.io/npm:@hotwired/turbo@7.3.0/dist/turbo.es2017-esm.js`  
  - Rails-UJS用CDN例: `https://ga.jspm.io/npm:@rails/ujs@7.0.4/lib/assets/compiled/rails-ujs.js`  
  - `curl -L URL -o vendor/javascript/ファイル名.js` で正しいJSを保存

## 学習内容6  
- **タグ**: アセット再生成  
- **タイトル**: assets:clobberとassets:precompileの流れ  
- **内容**:  
  - `bin/rails assets:clobber` でpublic/assetsを空っぽにする

- **タグ**: JavaScript, import  
- **タイトル**: application.jsに必要なimportを追加  
- **内容**:  
  - `app/javascript/application.js` にpinした全モジュールを import しないとSyntaxErrorやmodulepreload警告が出る  
  - 例:

    ```js
    import "@hotwired/turbo"
    import "@hotwired/stimulus"
    import "@hotwired/stimulus-loading"
    ```

## 学習内容8  
- **タグ**: プリロード, パフォーマンス  
- **タイトル**: modulepreloadとCSSプリロードの違い  
- **内容**:  
  - `modulepreload` はJSモジュール用、自動生成される  
  - CSSプリロードは `<link rel="preload" as="style" onload="this.rel='stylesheet'">` またはHTTPヘッダー `Link: </assets/application.css>; rel=preload; as=style` で行う  
  - Rails 6.1+は自動でLinkヘッダーを付与するため、HTMLにタグがなくてもプリロードされる  
  - 警告を消すにはヘッダー削除、タグに `as="style"` 指定＋onloadパターン、または通常の `stylesheet_link_tag` に戻す

## 学習内容11  
- **タグ**: Turbo, 導入  
- **タイトル**: Turbo導入の流れ  
- **内容**:  
  - `bin/importmap pin @hotwired/turbo --download`でvendor/javascriptにTurboを保存  
  - `config/importmap.rb`で`pin "@hotwired/turbo", to: "turbo.es2017-esm.js", preload: true`を設定  
  - `app/javascript/application.js`に`import "@hotwired/turbo"`を追加  
  - `bin/rails assets:clobber assets:precompile`でアセットを再生成
