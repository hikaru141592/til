```
results = [10, 20, 30, 40]
found = results.detect { |n| n > 25 }

```

## 学習内容2  
- **タグ**: Rails, Console, Turbo  
- **タイトル**: RailsコンソールのオブジェクトキャッシュとTurbo Frameキャッシュ  
- **内容**:  
Railsコンソールでモデルを取得すると、そのインスタンスはメモリ上にキャッシュされる。たとえば  
```
play_state = User.find_by(name: 'test5').play_state
```
とした後にデータベースを直接更新しても、同じplay_stateオブジェクトを参照し続けるため変更が反映されない。
この場合は`play_state.reload`を呼び出すことで、再度データベースから最新のレコードを取得できる。
また、Hotwire Turbo を使って <turbo-frame> で部分更新していると、ブラウザ側にもフレームキャッシュが働くため、Shift+F5などキャッシュクリア付きリロードを行わないと最新HTMLが読み込まれない場合がある。
以上の理由からコンソール操作時は.reload を必ず呼び出す、ブラウザ操作時 はShift+F5完全リロード（キャッシュクリア）でフレームを更新とすると、手動で状態を戻してすぐに画面に反映できる。
