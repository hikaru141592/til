## 学習内容1
- **タグ**: DB
- **タイトル**: どういうときにカラムにインデックスを設定すべきか
- **内容**:
データベースはインデックスを効かせることで大量レコードの中から該当行を高速に探せるようになる。
emailやfriend_codeのようにWHERE節でよく使う列にはインデックスを貼っておくとパフォーマンス向上に役立つ。

## 学習内容2
- **タグ**: 暗号化,セキュリティ
- **タイトル**: Encrypted Credentials
- **内容**:
秘密情報を安全に隠しておく鍵付きの保管場所。
「メール送信のパスワード」や「LINEのAPIキー」といった、ぜったい人に見られたくない情報を入れておく。
そこ（credentials.yml.enc）は暗号化されていて、開けるには鍵（master.key）が必要となる。
使うにはまず、
```
docker compose run --rm web rails credentials:edit
```
とし、credentials.yml.encとmaster.keyを生成。  
credentials.yml.encの中身を、
```
smtp:
  user_name: "your@example.com"
  password: "supersecret"
line:
  channel_token: "LINEのトークン"
```
のように保存すると、自動で暗号化された状態で格納される。
アプリから取り出すにはRailsのコード中で、
```
Rails.application.credentials.dig(:smtp, :password)
```
のように呼ぶと、安全に中のパスワードを取り出せる。
メール送信や外部サービス連携等を使っている場合は用いるべき。
