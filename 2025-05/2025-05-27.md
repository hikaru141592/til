## 学習内容1  
- **タグ**: Rails, AssetPipeline, CSS
- **タイトル**: ISO8601形式
- **内容**:
ISO8601とは、日時を「YYYY-MM-DDThh:mm:ss±hh:mm（例：2025-05-27T18:45:00+09:00）」のような形式で表す国際規格のこと（±hh:mmはタイムゾーンオフセット）。  
この形式を使うとどのタイムゾーンのいつなのかが明確になるため、サーバー間やクライアント–サーバー間での時刻比較に適している。  
.iso8601メソッドはRubyのTime#iso8601メソッドで、タイムゾーン付きの文字列を生成。
またTime.iso8601(params.require(:state_timestamp))　のようにすることで文字列をタイムオブジェクトに変換できる。  
Rubyの標準ライブラリ（stdlib）には、timeというモジュールが含まれているので、これを読み込む（requireする）ことでTime#iso8601インスタンスメソッドとTime.iso8601(string) クラスメソッド（ISO 8601 文字列→Time オブジェクトへの変換）が使えるようになる。  
※Ruby をインストールした時点で使える標準機能のため追加のGem インストールやBundlerでの設定は不要  
```
require 'time'

t = Time.now
iso_string = t.iso8601          # => "タイムゾーン付き文字列生成：2025-05-27T18:50:00+09:00"
parsed = Time.iso8601(iso_string)  # => 文字列をタイムオブジェクトに変換：#<Time 2025-05-27 18:50:00 +0900>
```

## 学習内容3  
- **タグ**: タイムスタンプ
- **タイトル**: タイムスタンプの比較
- **内容**:
タイムスタンプを比較する際、クライアント送信タイムスタンプとサーバーの最新タイムスタンプが同じはずなのに異なる判定になる場合がある。  
これはサーバー側の身マイクロ秒以下の情報を持つようなことがあるためで、Time#to_iを使い切り捨てることで等しい判定にすることができる。
