## 学習内容1  
- **タグ**: Ruby, メソッド  
- **タイトル**: sendメソッドとpublic_sendメソッドの違い
- **内容**:  
sendはプライベートメソッドも呼び出せてしまうのに対し、public_sendublicメソッドのみ呼び出せる。  
安全性・可読性の観点で公開メソッドだけを呼びたい場合は、public_sendを使うのが推奨される。

## 学習内容2  
- **タグ**: Ruby, メソッド  
- **タイトル**: tryメソッド
- **内容**: 
Rails（Active Support）が提供するメソッド。
`object.try(:some_method)`ではobjectがnilでない場合はobject.some_methodを実行し結果を返し、objectがnilの場合は例外を投げずにnilを返す。
例えば以下のように活用できる。
```
item = current_user.user_items.find_by(code: 'XXX')
count = item.try(:count)  # item がnilならここでnilを返す
```
