## 学習内容1
- **タグ**: Sorcery, 認証基盤
- **タイトル**: Rails 認証基盤（Sorcery）の基本
- **内容**:
  1. インストール手順  
     - `gem 'sorcery'` を追加 → `rails generate sorcery:install` → 必要なサブ機能を有効化 → `db:migrate`  
  2. モデル設定  
     - `authenticates_with_sorcery!` を User モデルに記述すると認証メソッドが自動提供される  
  3. require_login  
     - コントローラに `before_action :require_login` を設定し、未認証時はリダイレクトさせる  
  4. オプション機能  
     - `rails generate sorcery:install activity_logging` でログイン日時などを記録  

## 学習内容2
- **タグ**: バリデーション
- **タイトル**: Railsのバリデーション
- **内容**:
  1. 条件付きバリデーション  
     - `if: ->{ new_record? || changes[:crypted_password] }` で新規作成・パスワード変更時のみ実行  
  2. 主なオプション  
     - `presence: true`：空 or nil 禁止  
     - `uniqueness: true`：重複禁止  
     - `format: { with: regex }`：正規表現検証  
     - `length: { minimum:, maximum: }`：文字数制限  
     - `inclusion: { in: range }`：範囲チェック   

## 学習内容3
- **タグ**: 資産管理
- **タイトル**: Rails8の資産管理
- **内容**:
  1. Propshaft vs Sprockets  
     - Rails8はデフォルトでPropshaftを採用  
     - 旧Asset Pipeline（Sprockets）は `app/assets` 系を参照  
  2. Importmap設定  
     - `config/importmap.rb` で `pin` 指定 → `<%= javascript_importmap_tags %>` で読み込み  
  3. ビルド結果読み込み  
     - `app/assets/config/manifest.js` に `//= link_tree ../builds .css` を追加して配信

- **タイトル**: CSSバンドリング
- **内容**:
  1. cssbundling-rails

## 学習内容6
- **タグ**: デバッグ, トラブルシュート
- **タイトル**: InvalidRegularExpressionエラー
- **内容**:
PG::InvalidRegularExpressionエラーは、PostgreSQLが受け付けない正規表現リテラルを含むSQLが実行されたために起きてるもの。
マイグレーションやスキーマにチェック制約（CHECK）などで Ruby 形式の正規表現（\d や \A…\z）をそのまま書いてしまっているのが原因かと思われる。
