## 学習内容1
- **タグ**: Ruby, コーディング試験対策
- **タイトル**:できるだけ少ない硬貨で支払ったときの硬貨の枚数計算
- **内容**:
```
x = gets.to_i
a = x / 500
b = (x - a * 500) / 100
c = (x - a * 500 - b * 100) / 50
d = (x - a * 500 - b * 100 - c * 50) / 10
e = (x - a * 500 - b * 100 - c * 50 - d * 10) / 5
f = (x - a * 500 - b * 100 - c * 50 - d * 10 - e * 5) / 1
puts a + b + c + d + e + f
```
以上は以下のように書き換えられる。
```
x = gets.to_i
coins = [500, 100, 50, 10, 5, 1]
count = 0

coins.each do |coin|
  count += x / coin
  x %= coin
end

puts count
```
