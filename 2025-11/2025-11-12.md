### 学習内容1
- **タイトル**: gitコマンド
- **内容**:
  - git diffコマンド
    - git diff HEAD   ：作業ツリーと最新のコミットの差分を確認
    - git diff HEAD^  ：作業ツリーと1つ前のコミットの差分を確認
    - git diff HEAD^^ ：作業ツリーと2つ前のコミットの差分を確認
    - git diff HEAD~1 HEAD：1つ前のコミットと最新コミットの差分を確認

### 学習内容2
- **タイトル**: Rspecのインストール
- **内容**:
  - インストール時に生成されるファイル
    - `.rspec`   ：`rspec`コマンド使用時のデフォルトオプションを設定
    - `spec/spec_helper.rb` ：Rspecの全体的な設定
      - インストール時`.rspec`で`--require spec_helper`をデフォルトオプションとしてるのでデフォルトで読み込まれる
      - Railsを読み込まずにRspecだけで何かしらRubyのコードをテストするのにも使う
    - `spec/rails_helper.rb` ：Rails特有の設定を書く
      - インストール時`.rspec`に`--require rails_helper`がないことに注意
  - `spec/support`ディレクトリ：共通のヘルパーメソッドや共有コンテキストを一箇所に集約して、テスト間で再利用できるようにする

### 学習内容3
- **タイトル**: その他
- **内容**:
  - Gemfileの`require: false`について
    - Rubocopなどは通常コマンドで使用するもので、Railsアプリの中からRubocopのメソッドを呼び出すことはない。このように自動読み込みさせる必要がないGemには`require: false`を指定しておく。
    - `ruboCop-rspec`というgemは、Rubocopの検査を拡張しRspecテストコード固有のルールを追加し検査するようにできる。
