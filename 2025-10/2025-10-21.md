## 学習内容1
- **タグ**: 学習記録, Rails
- **タイトル**:Active Job（基礎復習）
- **内容**:
  - Active Jobとは
    - Active Jobは、Ruby on Railsに標準で備わっている非同期処理（バックグラウンドジョブ）を扱う仕組みのこと。
    - 今すぐ実行しなくてもいい処理をあとで別のスレッドやサーバーで実行するためのフレームワークである。
    - ジョブという単位で処理を定義し、キューイングシステムに渡して実行する。
    - 使用する場面
      - 処理が重い
      - 時間がかかる：画像のリサイズ・圧縮・サムネイル生成のような画像処理など
      - すぐにレスポンスを返したい：LINE通知・SNS投稿など外部サービスとの通信処理など
      - 定期実行：毎日バッチ処理を動かすなど
    - 使い方(例)
      - ジョブファイルの作成
        - `rails generate job send_welcome_email`で`app/jobs/send_welcome_email_job.rb`を作成
          ```
          class SendWelcomeEmailJob < ApplicationJob
            queue_as :default

            def perform(user)
              UserMailer.welcome_email(user).deliver_now
            end
          end
          ```
      - 呼び出し
        - `SendWelcomeEmailJob.perform_later(@user)`で非同期実行呼び出し
        - `SendWelcomeEmailJob.new.perform(user)`で同期実行呼び出し
      - バックエンド（アダプター）
        - Active Jobはバックエンド（キューアダプター）と呼ばれる仕組みを使って実際にジョブを処理する。
        - アダプターの例
          - async:	デフォルト。Rails内でスレッドを使って非同期実行（開発向け）
          - sidekiq:	高速で人気のジョブキュー（本番環境でよく使う）
          - resque:	Redisベースの古典的なジョブキュー
          - delayed_job:	DBベースのジョブキュー
        - 設定は`config/application.rb`や`config/environments/production.rb`などで行う
          ```
          config.active_job.queue_adapter = :sidekiq
          ```
