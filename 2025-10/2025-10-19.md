## 学習内容1
- **タグ**: 学習記録, Rails
- **タイトル**:Active Storage（基礎復習）
- **内容**:
  - Active Storageは、Railsに標準搭載されているファイルアップロード機能のこと。
  - 画像・動画・PDFなどのファイルをモデルに紐づけて保存・表示・変換できる仕組みを提供。
  - これのおかげでRails5.2以降、CarrierWaveやShrineのような外部ライブラリを使わずに、Rails公式だけで完結できるようになった。
  - 基本的な仕組み
    - Active Storageは、ファイルを「アプリ内」ではなく「ストレージ」に保存する。
    - Railsアプリ内のDBには実際のファイルは保存せず、ファイルのメタデータ（ファイル名・パス・サイズなど）だけを記録。
  - 保存先（ストレージ）の種類
    - 設定ファイル`config/storage.yml`に定義。
      - 例
        - 開発環境: ローカルディスク (:local)
        - 本番環境: Amazon S3、Google Cloud Storage、Azureなどクラウド
  - 基本的な使い方
    - userにアバター画像や複数のサブ画像を設定できるようにする場合を例に考える
      - モデル
        ```
        class User < ApplicationRecord
          has_one_attached :avatar  # 単一ファイル
          has_many_attached :photos # 複数ファイル
        end
        ```
      - コントローラー
        ```
        def create
          @user = User.new(user_params)
          @user.save
        end

        private

        def user_params
          params.require(:user).permit(:name, :avatar, photos: [])
        end
        ```
  - DBマイグレーションが必要となることに注意
    - Active Storageを導入するときは、専用のテーブルを作成するマイグレーションが必要
      ```
      rails active_storage:install
      rails db:migrate
      ```
      - これで以下のactive_storage_blobs（ファイル情報）テーブルとactive_storage_attachments（モデルとの関連）テーブルが作成される。
