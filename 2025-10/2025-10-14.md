## 学習内容1
- **タグ**: 学習記録, ruby
- **タイトル**:ハッシュの扱い方（基礎復習）
- **内容**:
```
# 空ハッシュの作成
none = {}

# 初期化①(シンボルがキー)：キー/バリューをセットし初期化する作成
user = {
  name: "Hikaru",
  age: 25,
  language: "Ruby"
}

# 初期化②(シンボルがキー)：これは上記の初期化と同値
user = {
  :name => "Hikaru",
  :age => 25,
  :language => "Ruby"
}

# 値の追加/変更
user[:hobby] = "Programming"   # 追加
user[:age] = 26                # 変更

# 値の取り出し方
puts user[:name]

# 値の削除
user.delete(:language)

# 初期化(シンボルが文字列)：初期化②(シンボルがキー)と似ている
user = {
  "name" => "Hikaru",
  "age" => 25,
  "language" => "Ruby"
}

# 値の追加/変更
user["hobby"] = "Programming"   # 追加
user["age"] = 26                # 変更
```
