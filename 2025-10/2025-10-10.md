  - フォームオブジェクトとは
    - 複雑なフォーム入力処理を整理・簡潔に保つための専用クラスのこと。
    - Railsのモデルを直接使うのではなく、「フォーム入力のためだけに作る仮のモデル」のような存在。
    - 例：ユーザー登録フォームで、UserとProfileの2つのテーブルに同時にデータを保存
      - 通常
        ```
        def create
          user = User.new(user_params)
          profile = Profile.new(profile_params)
          if user.save && profile.save
            redirect_to root_path
          else
            render :new
          end
        end
        ```
      - フォームオブジェクト使用
        - UserRegistrationFormクラス
          ```
          class UserRegistrationForm
            include ActiveModel::Model  # ← バリデーションなどが使えるように

            attr_accessor :name, :email, :age

            validates :name, :email, :age, presence: true

            def save
              return false unless valid?
              user = User.create(name: name, email: email)
              Profile.create(user: user, age: age)
            end
          end
          ```
        - コントローラ
          ```
          def create
            form = UserRegistrationForm.new(params[:user_registration_form])
            if form.save
              redirect_to root_path
            else
              render :new
            end
          end
          ```
    - メリット
      - コントローラがシンプルに
      - 本来1テーブル1モデルという原則を保てるのでモデルが汚れない	
      - 複数モデルにまたがるバリデーションを1箇所に定義できる
